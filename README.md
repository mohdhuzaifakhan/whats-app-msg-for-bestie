# Gift for My Bestie 💌 (Serverless WhatsApp Gift Web App)

A lightweight, high-aesthetic interactive web app to build and send personalized digital gifts to your best friend with custom love notes, photos, polaroids, sound effects, themes, and secret memory unlocks.

## 🚀 No Server Required!
This app is **100% serverless and client-side**. 
- You **do not** need `node server.js` or any backend server.
- Gifts, photos, and messages are compressed and encoded directly into the URL fragment (`#gift=...`).
- It can be opened directly in any browser (`index.html`) or hosted for **FREE** on static platforms like **GitHub Pages**, **Vercel**, **Netlify**, or **Cloudflare Pages**.

## 🎁 How It Works

### 1. Sender (Creator View)
- Open `index.html` in your browser.
- Enter your bestie's name, your name, your WhatsApp number (optional).
- Write a heartfelt message and an inside joke/secret memory.
- Pick a visual theme (Soft Rose, Starlight, Sunshine, Emerald).
- Upload up to 3 photos (compressed automatically in your browser into lightweight polaroids).
- Click **"Copy WhatsApp Gift Link"** or **"Share Directly on WhatsApp"**.

### 2. Recipient (Bestie View)
- When your friend opens the WhatsApp link, **the creation form is COMPLETELY HIDDEN**.
- Your friend sees an interactive surprise envelope with floating hearts and sparkles.
- Tapping the envelope plays a magical sparkle chime sound effect and reveals:
  - 📸 Interactive Polaroid Memory stack with taped edges.
  - 📜 Your handwritten-style love letter.
  - 🔒 Secret inside joke lock box (taps to unlock).
  - 💬 Direct WhatsApp button to send a reply back to you!

## 🌐 How to Host & Share

1. **Option A: GitHub Pages / Netlify / Vercel (Recommended for WhatsApp links)**
   - Push this directory to GitHub or drag-and-drop into Netlify/Vercel.
   - Use your free `https://your-app.netlify.app` link to generate and send gift links to anyone on WhatsApp!

2. **Option B: Local Browser Testing**
   - Double-click `index.html` to open it in any browser!
